# 一周年赠礼

九月是开始做小手机项目的一周年，不指定某一天。赠礼是朋友提供的两张壁纸和一个头像框，原文件保存在 `public/anniversary/`，没有裁切、重绘或压缩。

三份作品作者均为 **哈基米欠我钱**。赠礼弹窗（包括换装选择页）、手机/聊天壁纸自选区和气泡工坊头像框选项都显示署名，统一读取 `ANNIVERSARY_ARTIST`。

- **弹窗**：设备当地的 2026 年九月，数据和开机动画就绪、解锁并处理完已有启动提醒后显示。点「收下赠礼」、关闭或成功应用后，`sullyos_first_anniversary_seen_v1` 记为已读。本会话还有一次性保护；不依赖角色时区，不会在下一年重复周年活动。
- **收藏**：三份素材始终可以自选，不受日期、是否看过弹窗、角色数量或付费状态影响。累充展示固定为 `¥ 0.00`，仅是免费赠礼的玩笑文案，不涉及余额、支付或 API。
- **一键应用**：用户选一个角色，再勾选头像框、聊天背景、手机桌面壁纸。两个背景各自可选款式；头像框给这段聊天中的用户和角色一起戴。只有手机桌面壁纸是全局设置，独立锁屏壁纸仍遵循已有规则。
- **底部操作**：并排的切角按钮，左侧浅色「收下赠礼」，右侧紫金色「立即换装」；进入角色选择页后主按钮变为「确认换装」。短暂扫光、悬停和按压反馈遵循系统减少动态效果设置。
- **头像框**：给所选角色生成 `anniversary-frame-<角色 id>` 气泡主题副本，保留现有两侧气泡、贴纸和自定义 CSS。其他角色共用的原主题不被改写。重复应用复用该角色的副本 id。
- **手动入口**：外观 → 手机壁纸；聊天设置 → 聊天背景；气泡工坊 → 头像挂件。工坊里可编辑任意一侧，保存和应用继续走原有流程。

## 原图为什么直接放会偏

头像框原图为 1080 × 1440，透明画布中心是 `(540, 720)`，头像开口中心约为 `(514, 705)`。默认按头像宽度、画布中心放置，大小与中心都对不上。

内置款预设为缩放 `1.8`、X `54.3%`、Y `52.5%`、旋转 `0`，头像在使用此框时裁为圆形。工坊预览、私聊和群聊通过 `avatarDecorationImageStyle` 共用定位；用户上传的其他挂件仍沿用原来的默认值。
