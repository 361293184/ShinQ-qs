# SAR 个人线

当前实现核对：2026-09-11。用户操作总览见 [SAR 活动室怎么玩](./sar-user-guide.md)。

凯恩与艾文的原稿目前覆盖一至三星。名册保留五颗星，四、五星不生成临时剧情。

## 日常与回忆

- 点击常驻 NPC 才进入对话；不打断用户在房间里的其他玩法。NPC 隐藏时不主动触发。
- 两人分别按本地自然日记录一次随机结果：80% 有话题、20% 只有日常问候。刷新、切页、跨标签页不会重抽；时钟回拨不会额外产生一次机会。
- 本星级十个普通话题不重复；已完成的话题、彩蛋和遇见也不会重新抽到。有普通话题时，已开放彩蛋有 20% 机会替代当天普通话题；普通话题耗尽后，星级事件直接开放，不额外抽概率或等待一天。三星后仍可遇到尚未完成的已开放彩蛋，不补写四、五星。
- 对话关闭后保留节点、台词、分支、表情与照片草稿。跨天先续完这段，再进行新的日常。
- 星级事件完整结束才点亮对应星。Sully 偶遇只在本尊实际加入 SAR 时发生，内置 ID 优先，因此重命名不影响识别。
- 已完成内容收入「随身仓库 → 图鉴 → 名册 → 回忆」。回看使用独立内存游标，不写入进度、不发奖、不续限时优惠、不再发送私聊彩蛋。

名册的「人物档案」保留两人完整原文简介；回忆按星级事件、日常话题、彩蛋与遇见分组，未完成项只显示通用锁定标题。名册是用户与这两位 NPC 的进度，不随仓库切换到哪个角色而变化。返回依次回到名册、图鉴和仓库。

## 对话与镜头

个人线默认单人：本人讲话时居中；只有另一位 NPC 实际发言才临时双人同框，本人再次讲话立即恢复单人。台词只是提到对方、或设定听者表情，都不会让对方出场。叙述沿用最近说话者，情绪与镜头状态一起保存；续看与回放使用同一规则。凯恩旧初遇也以凯恩为主角，艾文功能引导保持单人。

证件、合照、物品或恐龙等特殊演出使用主画面，台词旁保留当前角色的情绪头像。玩家可随时离开再续读，不要求一次读完整段。个人线来自固定原稿，不调用世界意志或 LLM 续写，与五十轮芯片演绎分别保存。

## 奖励与演出

剧情和奖励存于 `vr_fishing_market_v1.sarFamiliarity`，与钱包、模块、鱼获使用同一个加锁事务。每个已发奖励的节点保留唯一记录，重复点击和跨页竞争不会重复发放。存储失败时整笔回滚。

- 凯恩：管理员证演出；经用户确认的成员证；随分支保存结论的会议记录；可调构图、缩放、取景、加入自家角色的合照；带用户标签的旧式存档卡。
- 艾文：猫科语法包、关键词消音器、随机标准恐龙、恐龙蛋、优惠券、隐藏称号、备用存档卡与专属 `aiven-chimera`。
- 三星物品堆是演出道具，只有明确赠送的物品入库。假称号、七折玩笑、加载失败提示也不产生真实资产。
- 券雨固定三张；礼炮、物品爆出和恐龙展示通过普通对话继续，不额外要求确认。成员证、拍照和神秘按钮保留实际操作。
- 折扣采用 30 分钟有效期：全店或当前货架随机一个商品八折。九折券按真实数量使用；不叠加，自动选择最佳单项，同价优先用限时折扣以保留券，金额向上取整且最低 1 鳞币。过期旧报价不会静默涨价扣款。
- 新档称号系统于艾文二星开放，获得的「听懂风的人」可在称号编辑器选用，不覆盖用户已有称号。旧档已有称号保留使用资格。
- 蛋由艾文三星话题送出并开放对应图鉴，退出随机垂钓池。旧档已有的蛋和历史收藏保留。专属混合恐龙不进入垂钓、普通随机赠礼或孵化池。
- Sully 彩蛋进入本地私聊消息队列，以固定投递 ID 去重，不调用模型。

## 素材与保存

13 张表情来自用户提供的 [SAR 素材仓库](https://github.com/qegj567-cloud/SullyOS-assets/tree/main/SAR)。凯恩使用 7 种、艾文使用 6 种合法表情；逐句选择，旁白保留上一个表情。`public/sar-portraits` 保留原画布比例及透明通道，转为最大边 1500 px 的 WebP，合计约 2.48 MB。本地加载失败时回落原 CDN。

纪念物保存当时的姓名、日期、图片引用、构图和选择；后续更换形象不修改旧照片。在自己的仓库选择「纪念」可看证件、照片、记录和卡片，「优惠券」显示真实未使用数量；它们不借用当前查看角色的钱包或背包。

完整 ZIP 的 `sarLocalState` 包含个人线与未完成草稿，嵌套 `blobref:` 经元数据扫描一并导出二进制图片，恢复时沿用原 token。纯文字备份剥离 `blobref:` 和内嵌图片，保留进度、纪念物文字、构图、分支、优惠及投递状态。备份包含奖励收据，因此恢复后继续阅读仍不会重复领奖。
