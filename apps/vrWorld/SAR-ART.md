# SAR 活动室美术对接

当前实现核对：2026-09-11。个人线流程与奖励见 [SAR 个人线](../../docs/sar-personal-lines.md)。

## 素材与空间

- `assets/sar-club-room.png` 是用户提供的 1348 × 2439 活动室原图。
- `assets/sar/room-walk-mask.png` 与底图同画布，绿色为钓鱼站位，橙红色为其他活动站位。白色不可站立。
- `assets/sar/room-hotspots.png` 提取五个设施中心；恐龙入口额外放在茶几 `(790, 1300)`。布告板、模块柜台、芯片陈列、扭蛋机、钓鱼与恐龙均连接原功能入口。
- `prototypes/sar-art/read-room-mask.py` 使用 Pillow 分析原始像素，生成 `utils/vrWorld/sarRoomMask.json` 的逐行色区和候选脚底位置；不修改源图。
- `sarRoomLayout.ts` 按角色 ID 稳定分配候选位置，检查色区、脚底范围、角色间距与设施按钮避让。满员进入候位名单，不把多人塞进同一个位置。布局不让角色穿过家具漫游。

凯恩、艾文的 chibi 分别对应用户原始 `6_0_1 (6).png`、`6_0_1 (12).png`。保留完整 472 × 472 透明画布，不裁 NPC 边距。NPC 和访客共享基础尺寸及脚底基线（原图脚底 y = 427，即底部透明边距 45 / 472）；访客原有自定义缩放、翻转仍保留。

## 对话立绘

`utils/vrWorld/sarArt.ts` 注册用户原画的 13 种表情：凯恩 `normal / happy / curious / embarrassed / serious / shy / aboutaster`，艾文 `normal / happy / interested / sad / shy / sleeping`。正式素材在 `public/sar-portraits/Caian` 和 `public/sar-portraits/Aiven`，保留透明通道与原画布比例，最大边 1500 px 的 WebP 合计约 2.48 MB。

`SARNpcArt.tsx` 优先按需加载本地 WebP，失败才经原 `CdnImg` 镜像链请求相应 PNG；仍失败则回退 normal，再失败显示重试。房间不预载全部立绘；切换表情时保留上一张已加载图片，成功 URL 在会话中复用。

`SARDialogueCast` 以当前个人线的 `lead` 为主角：本人讲话时单人居中；只有另一位 NPC 实际成为 `speaker` 才临时双人同框，凯恩左、艾文右，听者降低亮度但保持不透明。对话回到本人时恢复居中单人；仅提到对方名字或给听者设置表情不触发出场。叙述沿用最近说话者，断点续看与名册回放使用相同规则。凯恩既有初遇明确传入 `lead=caian`；艾文功能引导默认单人。

个人线演出由 `SARFamiliarityDialog.tsx` 与 `sar-familiarity-dialog.css` 承载。正文逐句使用指定表情，旁白保持最近情绪；证件、合照等特殊演出占据主画面时，台词边保留当前角色的情绪头像。关闭 NPC 的设置同时隐藏两人的房间与对话入口，设施仍可用。

既有初遇脚本的 98 句逐句指定说话者表情，覆盖凯恩全部七种立绘，并包含 19 处听者反应。`SARDialogueLine.castExpressions` 可在一人说话时保存另一人的表情，显示人数仍由 `lead / speaker` 决定。拆台台词当句让凯恩变为 embarrassed，回应继续保留尴尬；Aster 回忆、好奇追问和认真解释有配套情绪。`getSARDialogueNode` 先过滤条件台词，再逐句生成两人的表情数据快照；换分支重新计算。个人线则把当前表情与最近说话者随节点保存在断点中。

## 名册与特殊演出

「仓库 → 图鉴」用「收藏 / 名册」切换。名册采用暖白档案布局、人物立绘与完整原文简介，显示五颗星，只开放写好的前三星；已完成的话题、星级事件与彩蛋可回看，锁定项不泄露标题和内容。名册属于用户，不随仓库当前主人变化。

成员证使用用户当时的 chibi；会议记录显示实际分支结论；合照支持拖动/缩放人物、背景取景、修改自己形象和加入自家角色。合照与证件保存当时姓名、日期、图片引用和构图，仓库「纪念」可查看，后续换形象不改旧照片。回放只读，不重领纪念物。

礼炮、三张优惠券雨、物品堆和神秘按钮由原生 UI 动效实现，非交互特效可直接按普通对话继续。混合恐龙「？？？」复用正式橡皮泥 GLB 渲染器，规则与性能见 [恐龙箱庭](./DINOSAUR-GARDEN.md)。特效道具与真实赠品分别按剧情节点定义，不能根据画面出现什么就发什么。

## 临时立绘调节器

在 Vite 开发服务器打开 `/prototypes/sar-art/index.html?edit=portraits`（端口以启动输出为准）。

仅存在于原型入口，不进入 VRWorldApp。分别调整大小、左右、上下，以及前后遮挡顺序；实时使用正式对话组件预览，允许重叠。正 y 向上，x / y 均相对立绘场景尺寸；scale 的 150 对应已定稿的标准大小。参数保存在当前浏览器的 `sar-art:portrait-layout-draft:v1`，可复制、查看、恢复上一版。手机可收起控制面板。

双人同框的位置参数：两人 scale = 150，凯恩 x = 27，艾文 x = 75，y 均为 0，front = auto；单人模式居中。这些参数写入正式 CSS，临时编辑器的草稿不会自动覆盖正式参数。

既有初遇舞台按场景高度与原图宽高比确定人物尺寸，缩放原点在顶部中间。150% 对应场景高度减 24px；y = 0 时立绘画布顶部在黑框下方 24px。横屏按可用高度缩小；该初遇对白框竖屏固定 164px，长台词内部滚动，选项浮在画面中央。个人线使用独立阅读器及演出布局，不将初遇的固定尺寸套入合照和名册页面。
