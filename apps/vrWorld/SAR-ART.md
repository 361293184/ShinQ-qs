# SAR 活动室美术对接

## 素材与空间

- `assets/sar-club-room.png` 是用户提供的 1348 × 2439 活动室原图。
- `assets/sar/room-walk-mask.png` 与底图同画布，绿色为钓鱼站位，橙红色为其他活动站位。白色不可站立。
- `assets/sar/room-hotspots.png` 提取五个设施中心；恐龙入口额外放在茶几 `(790, 1300)`。布告板、模块柜台、芯片陈列、扭蛋机、钓鱼与恐龙均连接原功能入口。
- `prototypes/sar-art/read-room-mask.py` 使用 Pillow 分析原始像素，生成 `utils/vrWorld/sarRoomMask.json` 的逐行色区和候选脚底位置；不修改源图。
- `sarRoomLayout.ts` 按角色 ID 稳定分配候选位置，检查色区、脚底范围、角色间距与设施按钮避让。满员进入候位名单，不把多人塞进同一个位置。布局不让角色穿过家具漫游。

凯恩、艾文的 chibi 分别对应用户原始 `6_0_1 (6).png`、`6_0_1 (12).png`。保留完整 472 × 472 透明画布，不裁 NPC 边距。NPC 和访客共享基础尺寸及脚底基线（原图脚底 y = 427，即底部透明边距 45 / 472）；访客原有自定义缩放、翻转仍保留。

## 对话立绘

`utils/vrWorld/sarArt.ts` 注册 SullyOS-assets 的 `SAR/Caian` 七种表情与 `SAR/Aiven` 六种表情，通过现有 `CdnImg` 镜像链按需加载。房间不下载立绘；切换表情时保留上一张已加载图片，失败回退 normal，再失败显示重试。已成功的 URL 在会话中复用。

`SARNpcArt.tsx` 的 `SARDialogueCast` 同时摆放左侧凯恩、右侧艾文；正在说话的人亮起，另一人降低亮度但保持不透明。电影黑边和对白位于 `sar-npc-art.css`。凯恩既有初遇脚本及完成状态不变；艾文使用固定功能引导。关闭 NPC 的设置同时隐藏两人的房间与对话入口。

初遇脚本的 98 句逐句指定说话者表情，覆盖凯恩全部七种立绘，并添加 19 处听者反应。`SARDialogueLine.castExpressions` 可在一人说话时指定另一人的表情。所有拆台台词当句让凯恩变为 embarrassed，回应继续保留尴尬；Aster 回忆、好奇追问和认真解释分别有配套情绪。`getSARDialogueNode` 先过滤条件台词，再逐句生成完整的双人表情快照；保留当段反应，换分支从正常状态重新计算，避免上一段的情绪串入下一段。

## 临时立绘调节器

本地预览：`http://127.0.0.1:5182/prototypes/sar-art/index.html?edit=portraits`。

仅存在于原型入口，不进入 VRWorldApp。分别调整大小、左右、上下，以及前后遮挡顺序；实时使用正式对话组件预览，允许重叠。正 y 向上，x / y 均相对立绘场景尺寸；scale 的 150 对应已定稿的标准大小。参数保存在当前浏览器的 `sar-art:portrait-layout-draft:v1`，可复制、查看、恢复上一版。手机可收起控制面板。

用户已定稿：两人 scale = 150，凯恩 x = 27，艾文 x = 75，y 均为 0，front = auto。已写入正式 CSS 默认值；临时编辑器保留用于之后微调，草稿不会自动覆盖正式参数。

后续修正：按场景高度与原图宽高比确定人物尺寸，缩放原点在顶部中间。150% 对应场景高度减 24px；y = 0 时立绘画布顶部始终在黑框下方 24px，宽度单独变化只改变横向站位，不再把头顶推入黑边。横屏同样按可用高度缩小。对白框竖屏固定 164px，长台词内部滚动；选项独立浮在画面中央，不参与对话框或场景排版。
