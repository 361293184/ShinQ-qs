# 艾文的恐龙箱庭

移动端优先的橡皮泥模型箱庭。入口在 SAR 水域旁，也能从钓鱼收藏进入。没有咖啡店或战斗系统。原来的 SAR 活动室图片不变。

## 地图与美术

- 溪边草原：草坡、溪流、木桥、花丛、蘑菇、彩旗、营地。
- 贝壳海岸：弧形沙滩、浅水湾、棕榈树、灯塔、遮阳伞、贝壳、海星、玩具帆船。没有桥或草原的栅栏和彩旗。
- 火山探险：灰褐色岩台、橡皮泥熔岩、晶簇、化石压印、探险补给、圆火山和烟团。没有溪流、桥或彩旗。

三张地图分别构图，共用底座与低成本几何生成器。每张地图独立保存摆件和恐龙位置，所有角色共用每图六个恐龙名额。当前首版开放三张地图；尚未接活动解锁更多主题。用户和现有角色的收藏可一起摆放，归属不因摆放而改变。

恐龙以用户参考图为依据离线生成 GLB：连续的圆润身体、哑光顶点色、保留眼睛和表情，现有十二种收藏均有模型。UV 两通道作为身体和细节的换色权重，不需要贴图。六组配色及两个色盘只作用于当前单只；预览可取消。自由手绘尚未实现。

## 隐藏棋盘

`dinosaurGrid.ts` 固定 A～F 六行、每行五格。恐龙位置吸附到这三十个落点，朝向量化为八个方向。平常不显示棋盘；摆放时显示可以落下的圆点。每只只占一格，每图最多六只，摆件会封锁附近落点。灯塔、遮阳伞等固定布景也使用共用地标位置校验占位，手动摆放、角色动作和旧自由坐标迁移都会避让。用户可跨地图移动同一只恐龙，不产生副本。

角色模型可以输出具体 `slotId`，或 `anchorId + near/face`。代码负责查找空格、占位、摆件避让和朝向；任意自由坐标不进入执行器。手动摆件仍可自由摆放，有边界和碰撞检查。

## 身份、记录与存档

所有内容在既有 `vr_fishing_market_v1` 的 `dinosaurGarden` 中，完整进入原 SAR 本地备份。没有新的远端数据库。首次打开只赠送一只真实收藏项；账本标记避免反复领取，来源明确记录为艾文的赠礼。

单只身份绑定 `FishingCatch.id`，保留名字、配色、获得者/来源、原始用户状态、当前状态、地图/格位、固定状态和修订号。同种多只完全独立；赠送保留身份和经历，并向受赠角色写入事实回执。挂板或孵化中的藏品不能摆放；图鉴发现记录和当前持有数量分开。

十二种行为可选对象，并附用户原文。来访只追加当前状态和署名，不修改用户原文。事件历史不裁剪；可回复便签、定位恐龙、回看旧位置。还原仅在目标之后没有变化、旧位置仍空闲时允许，且追加还原事件，不抹去来访记录。

早期单桌预览会迁移为多地图，旧自由位置吸附到不冲突的格位，个体信息保留。损坏/未知结构不会被初始化覆盖，原始内容仍能通过既有备份导出。Web Locks 串行化本页和其他标签页的写入；验证抛错后也必须释放锁。

## 角色来访的实际边界

真实入口使用 `runVRSession` 原有角色人格、上下文和 API 优先级。一次会话选择评论、移动或续写中的一个动作；固定恐龙只接受评论。执行时重新读取存档，核对地图、修订号、所有权、格位和共同摆弄开关。切换正在查看的地图不会把角色动作挪到另一张图。

自动来访挂在原有彼方在线活动调度中，每角色至少间隔十二小时，全局二十四小时最多三次；用户手动邀请不受自动频率限制。**关闭应用期间不会新产生来访**，没有实现后台 Worker 来访，也不补刷离线天数。试玩页使用明确标注的“示例来客”固定回复，不调用模型；生产入口才调用用户配置的模型。

## 性能与验证

只加载、显示当前地图所需模型；图鉴近看只显示单只。地图静态几何按顶点色合批，模型每只一个绘制调用。DPR 上限 1.4、动画 30 fps 上限、1024 静态阴影，无后处理或水面折射；离屏/后台停画，关闭释放资源，支持减少动态效果。真机帧率尚未测量，不能把桌面模拟手机的结果当作真机性能保证。

单元测试：`dinosaurGarden.test.ts`、`fishingMarket.test.ts`、`fishingSession.test.ts`。覆盖独立身份、每图六只、跨图搬家、格位/朝向、占位、模型动作、原文保留、固定/过期结果、还原、赠送、存储损坏与锁恢复、旧存档迁移、原有钓鱼回归。角色测试使用假 API。

浏览器：`prototypes/dino-cafe/qa-garden.mjs` 检查 390/320 竖屏、横屏、触控旋转、格位点选、换色/取消/刷新、状态、来访/还原、三地图、全部新增模型。`qa-integration.mjs` 用真实 OS/Music Provider 检查 SAR → 箱庭 → 钓鱼收藏 → 箱庭，拦截远端请求。官方 web-game 客户端另跑实际帧推进与截图。测试截图、状态和构建产物在忽略的 `output/` 子目录。

图鉴中生物常识参考：[伶盗龙羽毛](https://www.nhm.ac.uk/discover/velociraptor-facts.html)、[副栉龙头冠](https://www.nhm.ac.uk/discover/dino-directory/parasaurolophus.html)、[翼龙分类](https://www.nhm.ac.uk/discover/the-truth-about-pterosaurs.html)、[蛇颈龙分类](https://www.nhm.ac.uk/discover/what-is-a-plesiosaur.html)。模型是夸张的橡皮泥玩具，不是古生物复原标本。
