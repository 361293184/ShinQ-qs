## 产品概述
SullyOS 拾光·番外功能的两项优化：让字数预设选项真正可选（当前点击 500/2000/5000 没有任何反应），并把转发给角色时的迷你书卡片视觉做得更精致、标题更花哨。

## 核心功能
- 番外字数选择：500 / 1000 / 2000 / 5000 / 自定义 真实可选，切到预设时正确联动显示字数与生成参数
- 番外卡片美化：书脊效果、装饰横线、衬线花体标题、徽章等细节


## 技术栈
- React + TypeScript + Tailwind CSS（沿用 SullyOS 现有技术栈）
- 不新增依赖、不改 PhoneShell/OSContext/index.html

## 实现方案

### Bug 1：字数预设按钮无效
根因（components/fanwai/FanwaiGeneratePage.tsx）：
- 第 87 行 `const wordCount = wordCountIsCustom ? customWordCount : DEFAULT_WORD_COUNT;` 把预设模式硬编码回 `DEFAULT_WORD_COUNT = 1000`
- 229-252 行的按钮 onClick 仅切 `wordCountIsCustom`，没有把选中的 `n` 写回 state
- active 判定 `(!wordCountIsCustom && wordCount === n)` 永远只命中 1000，其他按钮看起来"不可选"

修复：
- 新增 `wordCountPreset` state（默认 1000），纳入 SavedForm 持久化
- 删除 `DEFAULT_WORD_COUNT` 常量（或仅作 1000 兜底）
- `wordCount` 计算用 `wordCountPreset`：`const wordCount = wordCountIsCustom ? customWordCount : wordCountPreset;`
- 按钮 onClick 改为 `setWordCountPreset(n); setWordCountIsCustom(false);`（点击自定义时只切 `wordCountIsCustom`）
- active 判定改为 `(!wordCountIsCustom && wordCountPreset === n)`

### Bug 2：卡片视觉升级
目标：保留 w-60 紧凑迷你书比例同时，加入书脊、装饰线、衬线大字、徽章等细节，整体更有「书」的质感。

视觉策略（components/chat/MessageItem.tsx 2358-2395）：
- 封面：加大圆角（rounded-2xl），左侧书脊条（1/5 宽、暗一档同色系 + 1px 高光），顶部金色装饰线（h-px 渐变),顶部右侧羽毛/书形 SVG 装饰角章
- 标题：font-serif font-black text-[15px] tracking-tight 衬线加粗，行高紧凑（leading-tight），白色文字阴影让暖色背景上更立体,"XX 的番外" 副标题用斜体衬线 + 羽毛 icon
- 摘要保持 line-clamp-3
- 底部徽章：右上角圆角小徽章「拾光·番外」，金色背景 + 白字，圆角全圆
- 装饰：渐变方向与之前一致 (`from-[#FDE7D7] via-[#F7CBA8] to-[#EFB6C6]` 等)，opacity-30 噪点层（两个圆形装饰保留并加大）

### 实现要点
- 不动其他卡片分支（如 xhs_card / webpage_card）的视觉，避免大范围回归
- 不改 metadata 结构（仍为 `m.metadata.fanwaiStory`），所以旧消息兼容
- 字数修复合入 SavedForm 持久化（localStorage `os_fanwai_form_v1`），下次打开自动恢复上次选择
- 字体后备：保留 `font-serif`（SurilyOS 已有 Noto Serif / PingFang 衬线兜底）
