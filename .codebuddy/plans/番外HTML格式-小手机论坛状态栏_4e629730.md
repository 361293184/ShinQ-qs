## 产品概述
让番外支持 HTML 格式（小手机/论坛/状态栏三套预置模板 + AI 自由生成），默认仍为纯文字，仅在指令提到格式时切换。用沙盒 iframe 渲染 + 静态互动。

## 核心功能
- 指令关键词识别格式（小手机/论坛/状态栏），AI 兜底判断，多格式冲突第一个命中为准
- 三套预置模板（phone 小手机 / forum 论坛 / statusbar 状态栏）+ AI 自由生成（custom）
- HTML 番外用沙盒 iframe 渲染（禁脚本无 XSS），头像注入（blob 转 data URL，失败降级首字母圆）
- 生成页检测提示 + iframe 预览 + 确认后才收藏；保留返回键
- 拾光详情页按 format 分流渲染；聊天转发显示缩小预览图并跳拾光全屏
- 兜底：HTML 超长截断、生成失败降级纯文字+提示、存量番外零迁移

## 技术栈
- React + TypeScript（现有项目，沿用现有架构）
- 沙盒 iframe（复用现有 HtmlCard 组件 srcDoc + sandbox="allow-same-origin" 禁脚本机制）
- 头像 blob→data URL（复用 utils/blobRef.ts 的 resolveRefToDataUrl）
- 副 API 通道（复用现有 subBaseUrl/subApiKey/subModel，与文字番外一致）

## 实现方案
核心思路：默认纯文字流程完全不动；仅当指令含格式关键词时，走「格式识别 → 模板/AI 生成 HTML → 沙盒渲染 → 确认收藏」新链路。`FanwaiStory` 加 format/htmlType 字段（缺省 text 兼容存量）。

### 关键决策
- **目录**：现状是单文件 `utils/fanwaiGenerator.ts`，方案假设的 `utils/fanwai/` 目录需新建。新文件放 `utils/fanwai/`（formatDetector.ts、htmlTemplates.ts），生成器仍在原单文件扩展。
- **格式识别**：formatDetector 先做关键词表匹配（phone/forum/statusbar），返回 htmlType；无关键词但 AI 兜底开启时，让 AI 在输出中带格式标记解析。多关键词第一个命中为准。
- **生成**：命中模板 → 注入模板骨架（占位符）让 AI 只填内容别改结构；无模板 → AI 自由生成 HTML（约束无脚本、宽度自适应、美观、标签闭合、无外层阴影）。统一走副 API。
- **沙盒渲染**：直接复用 HtmlCard 的 srcDoc 机制封装一个 HtmlFanwaiView（小手机=手机框比例，论坛/状态栏=自适应宽度），避免重复造轮子。
- **确认收藏**：生成后先 iframe 预览，用户点确认才 handleCollect 落库；不满意重新生成。
- **转发**：HTML 番外转发走 fanwai_card，只喂标题+梗概给角色（全文不进上下文，与文字番外一致），聊天卡片显示缩小预览图并跳拾光。

### 性能与可靠性
- 生成为非流式单次请求（沿用现有 generateFanwai），无额外开销
- 头像 data URL 在生成时转换一次注入模板，避免运行时重复读取
- 沙盒禁脚本天然无 XSS；HTML 超长截断、生成失败降级纯文字+提示
- 存量番外 format 缺省按 text，渲染走旧逻辑，零迁移

## 实现注意
- `FanwaiStory.format` 缺省 text，渲染判断用 `format === 'html'`
- 头像用 resolveRefToDataUrl 转 data URL 注入，失败降级首字母圆；顺带修 FanwaiGeneratePage:186 blobref 破图
- HTML 输出前做长度截断（防撑爆）；解析失败降级纯文字
- 生成页保留返回键，HTML 预览与文字番外导航一致
- 不新建 API 通道，复用副 API；不改动记忆系统、HtmlCard 本体、文字番外流程

## 设计风格
番外 HTML 三套模板采用精致卡片风，沙盒 iframe 内渲染，静默嵌入拾光/聊天场景。三套模板各自独立但风格统一：浅色为主、圆角卡片、细边框、轻阴影（沙盒内保留，外层 HtmlCard 已去阴影）。整体追求「像真的聊天截图/论坛页/状态条」的沉浸感，静态互动靠纯 CSS 实现。

## 三套模板
- **小手机（phone）**：圆角细边框手机机身，顶部状态栏（时间=指令细节），聊天标题栏，左侧对方气泡（浅色+真实头像）、右侧用户气泡（主题色+真实头像），底部输入框占位。头像 blob 转 data URL，失败降级首字母圆；点击气泡纯 CSS 放大单条。
- **论坛（forum）**：顶部导航（返回+论坛名+搜索），标题/楼主/时间，正文，details 折叠回复，楼层首字圆头像，点赞 :checked 变红。
- **状态栏（statusbar）**：胶囊状态标签（头像+名字+状态描述，浅底圆角），可穿插正文前/中，AI 控制节奏。
