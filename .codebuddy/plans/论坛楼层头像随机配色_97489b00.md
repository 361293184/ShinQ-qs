## 用户需求
论坛番外生成后，楼层头像（76楼~80楼）颜色全是深灰/黑色系，视觉单调。希望**打乱随机**配色，让头像颜色丰富多样。

## 根因
`utils/fanwai/htmlTemplates.ts` 论坛模板的楼层头像硬编码内联样式 `background:#EDF0F7;color:#8A94A6`，AI 逐层复制结构时所有楼层头像颜色完全一致。

## 核心功能
- 论坛楼层头像颜色按楼层序号自动循环切换（5-6 种柔和色），不再全是同色
- 用 CSS `:nth-child(5n+k)` 按 DOM 兄弟顺序自动分配颜色（沙盒禁脚本，纯 CSS 方案最稳）
- 移除楼层头像的内联 background/color，改为由 CSS nth-child 规则控制
- 不影响 phone/statusbar/custom 模板
- 不破坏现有 .fw-floor-av 基础定义与现有楼层结构


## 技术栈
- HTML + CSS（论坛模板，TypeScript 字符串输出）
- CSS `:nth-child` 伪类（按 DOM 顺序自动循环）
- 沿用现有 React + TypeScript 项目架构
- 沙盒 iframe 禁脚本（纯 CSS 方案最可靠）

## 实现方案

### 关键决策
1. **CSS nth-child 配色**：在论坛模板 `<style>` 里给 `.fw-floor-av` 加 5 组 `:nth-child(5n+1)`、`:nth-child(5n+2)`、…、`:nth-child(5n+5)` 规则，每组分配一种柔和背景色 + 配套前景色（蓝/绿/橙/紫/粉 + 原浅灰）。AI 逐层复制 `.fw-floor` 结构时，颜色按楼层序号自动切换（1楼第1色、2楼第2色…5楼第5色、6楼回到第1色）。
2. **移除内联样式**：把楼层头像的内联 `background:#EDF0F7;color:#8A94A6` 移除（只保留尺寸/边框/圆角等），让 CSS 规则生效。
3. **保留兜底色**：基础 `.fw-floor-av` 仍保留原浅灰背景作为未匹配时的兜底。
4. **颜色选 5 种柔和色**（与现有 #EDF0F7 + #8A94A6 风格协调，不刺眼）。

### 性能与可靠性
- 纯 CSS 方案，浏览器原生 nth-child，无 JS 性能开销
- 沙盒禁脚本天然适配（无需 JS 随机）
- 渐变高斯，循环配色的视觉感与现有精致卡片风一致

## 落点
- `utils/fanwai/htmlTemplates.ts`：论坛模板 line 96-104 的 `<style>` 加 `.fw-floor-av:nth-child` 规则；line 81 楼层头像的 inline style 去掉 background/color

## 注意
- 只改论坛模板，不动 phone/statusbar/custom
- 颜色不刺眼，柔和为主（延续现有浅色风格）
- 选用的 5 种色：原浅灰（#EDF0F7）、淡蓝（#DBEAFE）、淡绿（#DCFCE7）、淡橙（#FFEDD5）、淡紫（#EDE9FE），各自配深色文字
