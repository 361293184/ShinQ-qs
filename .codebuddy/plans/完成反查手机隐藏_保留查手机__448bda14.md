## 需求概述
用户澄清了两个不同功能：
- **查手机（CheckPhone App）** = 用户查看**角色**的手机内容 → **保留**（桌面/皮肤入口 + 用户主动浏览功能）
- **反查手机（reverse）** = 角色查看**用户**的手机 → **全部隐藏**

之前误将"查手机 App"入口也一并隐藏（提交 9469dfd），需修正：恢复查手机 App 入口，只隐藏反查手机的全部入口。

## 核心功能
1. 恢复查手机 App（用户查角色手机）在默认桌面 + 手游/乙女/Companion 皮肤的入口
2. 隐藏反查手机（角色查用户手机）的全部入口：
   - 对话自动触发（applyAssistantPostProcessing）
   - 事件监听（OSContext 的 sullyos-reverse-request）
   - CheckPhone App 内部的反查记录页（openReversePanel / showReverse / ReversePanel）
   - CheckPhone App 内部的「让 TA 反查你的手机」按钮（requestReverse）
3. 反查手机相关代码文件保留（不删），日后可恢复

沿用现有 React + TypeScript + Tailwind，注释法隐藏（与代码库既有惯例一致），不引入新依赖、不重构结构。
